# 工薪实时桌面小卡片需求说明

## 1. 产品目标

使用 Electron 构建一个 Windows 桌面小卡片组件，用于实时展示用户当天和本月的工薪进度。软件常驻桌面或托盘，帮助用户直观看到当前时间、今日已过工时、今日已赚工资、本月已赚工资、本月已过天数、天气等信息。

核心体验关键词：

- 轻量：小窗体、不打断工作、资源占用低。
- 实时：按秒或按分钟刷新时间和薪资。
- 可配置：适配日薪、月薪、不同工作日历和休息日。
- 桌面化：支持置顶、透明背景、拖动位置、托盘菜单、开机自启动。

## 2. 目标平台

- Windows 10 / Windows 11。
- Electron 桌面应用。
- 初期优先单机本地配置，不依赖账号体系。

## 3. 核心功能

### 3.1 桌面小卡片展示

小卡片默认展示以下信息：

- 当前日期：例如 `2026年05月19日 周二`。
- 当前时间：例如 `14:36:28`。
- 今日已赚工薪：根据用户配置的薪资、工作时段、当前时间实时计算。
- 今日工时进度：展示百分比、进度条、已过工时 / 总工时。
- 天气：展示城市、天气状态、温度、空气质量或降雨提示。
- 本月已赚工薪：根据本月已完成工作日及今日已完成工时计算。
- 本月已过天数：展示自然日进度，也可补充本月工作日进度。

推荐展示结构：

- 顶部：日期、时间、天气。
- 中部：今日已赚工薪大数字。
- 下方：今日工时进度、本月统计。
- 底部：状态提示和快捷按钮。

### 3.2 薪资配置

支持两种薪资模式：

#### 日薪模式

用户配置：

- 日薪金额。
- 工作开始时间。
- 工作结束时间。
- 午休开始时间，可选。
- 午休结束时间，可选。
- 每周工作日，例如周一至周五。

计算规则：

```text
有效总工时 = 工作结束时间 - 工作开始时间 - 午休时长
今日已过有效工时 = 当前时间在工作时段内已累计的有效工作时间
今日已赚工薪 = 日薪 * 今日已过有效工时 / 有效总工时
```

边界规则：

- 工作开始前，今日已赚为 `0`。
- 工作结束后，今日已赚为完整日薪。
- 非工作日默认今日已赚为 `0`，可配置是否按加班日计算。
- 午休期间，今日已赚暂停增长。

#### 月薪模式

用户配置：

- 月薪金额。
- 每月计薪方式：
  - 按固定工作日数，例如 21.75 天。
  - 按当月实际工作日数。
- 工作开始时间。
- 工作结束时间。
- 午休时间。
- 每周工作日。
- 法定节假日和调休日，可手动维护，后续可接入节假日接口。

计算规则：

```text
当日折算日薪 = 月薪 / 本月计薪工作日数
今日已赚工薪 = 当日折算日薪 * 今日已过有效工时 / 有效总工时
本月已赚工薪 = 已完成工作日薪资 + 今日已赚工薪
```

其中：

```text
已完成工作日薪资 = 当日折算日薪 * 本月今日之前已完成工作日数
```

### 3.3 时间和进度

展示项：

- 今日自然时间进度，可选。
- 今日工作时间进度，核心展示。
- 本月自然日进度。
- 本月工作日进度。

刷新建议：

- 时间：每 1 秒刷新。
- 薪资：每 1 秒或 5 秒刷新。
- 天气：每 30 分钟刷新，手动刷新立即更新。

### 3.4 天气

用户配置：

- 城市，支持自动定位或手动选择。
- 天气服务 API Key，可选。
- 温度单位，默认摄氏度。

展示内容：

- 城市名称。
- 天气状态。
- 当前温度。
- 体感温度，可选。
- 空气质量或降雨概率，可选。

离线或接口失败时：

- 保留上一次成功天气数据。
- 显示更新时间。
- 提供轻量错误状态，例如 `天气更新失败`。

### 3.5 桌面窗口行为

必备：

- 无边框小窗体。
- 窗口可拖动。
- 窗口位置记忆。
- 支持置顶。
- 支持锁定位置，避免误拖动。
- 支持托盘图标。
- 托盘菜单包含显示 / 隐藏、设置、刷新天气、退出。
- 支持开机自启动。

推荐补充：

- 鼠标穿透模式：允许点击穿过小卡片，可通过托盘关闭。
- 透明度调节。
- 紧凑模式 / 标准模式。
- 主题模式：深色 / 浅色 / 跟随系统。
- 多显示器位置记忆。
- 窗口吸附屏幕边缘。
- 停靠屏幕边缘自动收起：当窗口贴近屏幕边缘时，可自动折叠为一条窄条，仅露出提示条用于唤回。

#### 3.5.1 主题模式

支持三种主题模式：

- 深色主题：默认推荐，适合长期悬浮在桌面上，降低视觉干扰。
- 明亮主题：适合浅色桌面背景，使用浅色卡片、深色文字和柔和边框。
- 跟随系统：监听 Windows 系统应用主题变化，自动切换深色或明亮主题。

主题切换要求：

- 切换后即时生效，不需要重启应用。
- 设置面板和桌面小卡片使用同一主题。
- 跟随系统模式下，仍保留用户透明度、紧凑模式等个性化配置。
- 主题色、文字色、进度条、卡片背景应通过统一 token 管理，避免散落硬编码。

#### 3.5.2 靠边收起

支持将小卡片停靠到屏幕上、下、左、右边缘后自动收起。

行为规则：

- 用户拖动窗口靠近屏幕边缘时，若开启靠边收起，则自动吸附到最近边缘。
- 静止一段时间后自动折叠，默认延迟 `800ms`，可配置。
- 折叠后仅露出一条窄条，宽度或高度建议 `8px - 16px`，用于提示收起位置。
- 鼠标悬停到提示条时展开完整卡片。
- 鼠标离开卡片后，再次按延迟自动收起。
- 锁定位置开启时，仍允许从提示条展开，但不允许拖动改变停靠边缘。
- 多显示器场景下，停靠边缘应基于当前窗口所在显示器计算。

提示条设计：

- 左右边缘：显示竖向条形，带轻微高亮或短文本，例如 `¥`、`工薪`。
- 上下边缘：显示横向条形，可展示小额实时数字或进度色条。
- 提示条需保持足够点击区域，避免过窄导致难以唤回。
- 明亮和深色主题下提示条都要有清晰对比度。

### 3.6 设置面板

设置项建议：

- 薪资模式：日薪 / 月薪。
- 日薪金额或月薪金额。
- 计薪工作日规则。
- 工作开始时间。
- 工作结束时间。
- 午休时间。
- 工作日选择。
- 节假日 / 调休日维护。
- 城市和天气源。
- 窗口置顶。
- 开机自启动。
- 透明度。
- 主题模式：明亮 / 黑暗 / 跟随系统。
- 靠边收起：开启 / 关闭。
- 收起提示条尺寸。
- 收起延迟。
- 刷新频率。
- 数字格式：保留小数位、货币符号。
- 隐私模式：隐藏具体薪资，只显示百分比或模糊金额。

## 4. 非功能需求

- 启动速度：冷启动尽量控制在 2 秒内。
- 常驻资源：空闲 CPU 占用应接近 0，内存占用尽量可控。
- 本地优先：配置保存在本地，不上传薪资数据。
- 稳定性：天气接口失败不影响薪资和时间展示。
- 可维护：薪资计算逻辑独立于 UI，方便单元测试。

## 5. 推荐技术方案

### 5.1 Electron 结构

```text
main process
  - 窗口创建与托盘
  - 开机自启动
  - 本地配置读写
  - 天气请求代理

renderer process
  - 桌面卡片 UI
  - 设置面板 UI
  - 实时展示与交互

shared
  - 薪资计算
  - 日期和工作日规则
  - 配置类型定义
```

### 5.2 建议依赖

- Electron：桌面容器。
- Vite：开发构建。
- React 或 Vue：渲染层，二选一。
- electron-store：本地配置持久化。
- dayjs：日期时间处理。
- lucide-react 或同类图标库：小图标。
- auto-launch 或 Electron 原生 login item：开机自启动。

## 7. 计算验收标准

- 工作开始前，今日已赚工薪为 0。
- 工作时间内，金额随有效工作时间线性增长。
- 午休期间，金额暂停增长。
- 工作结束后，今日已赚工薪等于日薪或折算日薪。
- 非工作日默认不计薪。
- 本月已赚工薪包含今日之前已完成工作日和今日实时进度。
- 月薪模式下，本月实际工作日数可正确排除周末和手动节假日，并纳入调休日。

## 8. 交互验收标准

- 主题切换为明亮、黑暗或跟随系统后，小卡片和设置面板立即应用对应主题。
- 跟随系统模式下，Windows 系统主题变化后应用自动同步展示主题。
- 开启靠边收起后，窗口拖动到屏幕边缘能吸附并折叠为提示条。
- 鼠标悬停提示条后，完整小卡片能平滑展开。
- 鼠标离开展开区域后，小卡片按配置延迟再次收起。
- 关闭靠边收起后，贴边窗口保持完整显示，不自动折叠。
- 多显示器下，收起位置保存在对应显示器边缘，不应跳回主屏。

第一版建议先完成：

- 桌面卡片主界面。
- 日薪 / 月薪配置。
- 工作时段和午休配置。
- 今日已赚、本月已赚、今日工时进度、本月天数进度。
- 本地配置保存。
- 窗口置顶、拖动位置记忆、托盘菜单。
- 开机自启动开关。
- 明亮 / 黑暗 / 跟随系统主题切换。
- 靠边收起和提示条唤回。
- 手动城市天气展示。

第二版再补充：

- 法定节假日自动同步。
- 鼠标穿透。
- 紧凑模式。
- 薪资隐私模式。
- 自动更新。
- 多显示器增强。

## 10. 设计方向

桌面卡片建议默认采用深色半透明玻璃质感，避免过强干扰。明亮主题使用浅色半透明卡片、深色文字和柔和阴影，适配浅色桌面背景。核心数字应足够醒目，但整体宽度控制在桌面组件范围内。

推荐尺寸：

- 标准模式：`360 x 520`。
- 紧凑模式：`320 x 220`。

视觉原则：

- 今日已赚工薪是第一视觉层级。
- 时间和天气保持轻量。
- 进度条表达工时推进。
- 设置入口不抢占注意力。
- 卡片圆角克制，建议 8 到 14 像素。
- 靠边收起时露出的提示条必须清楚但克制，避免形成桌面噪音。
